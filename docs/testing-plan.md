# omaxy — план и протокол тестирования всех режимов

Проблематика: часть сервисов (в т.ч. облачные LLM — OpenAI/Anthropic и др.)
блокируется по геолокации (RU-IP → 403 / region-block). Тест проверяет, что
omaxy корректно работает в каждом режиме и что смена геолока-выхода реально
меняет доступность таких сервисов.

## Режимы
| # | Режим            | tun | route_mode   | Что ожидаем |
|---|------------------|-----|--------------|-------------|
| 1 | прямой (выкл)    | –   | –            | базовая картина: что блокируется провайдером/провайдерами LLM |
| 2 | TUN direct-local | ✔   | direct-local | весь внешний трафик через сервер; LAN/приватные — напрямую |
| 3 | TUN global       | ✔   | global       | всё через туннель, включая LAN-диапазоны (ожидаем недоступность локалки — зафиксировать) |
| 4 | SOCKS/HTTP (без TUN) | ✘ | –        | xray слушает 10808/10809, система НЕ ходит через туннель |
| 5 | смена сервера на лету | ✔ | direct-local | маршруты не должны «оседать» старой петлёй |
| 6 | стоп демона      | –   | –            | xray умирает (PDEATHSIG), маршруты/ПДДNS снимаются |

## Проверяемые метрики (каждый режим)
- M1 внешний IP (`api.ipify.org`) — чей exit: домашний / RU-сервер / зарубежный
- M2 задержки: TCP-ping активного сервера
- M3 LLM-доступность (гео-блок провайдеров):
  - https://api.openai.com/v1/models (ожидаем 401 без ключа, 403 region-block — признак гео)
  - https://api.anthropic.com/v1/messages (401/403 аналогично)
  - https://generativelanguage.googleapis.com (Gemini)
  Код ответа + country exit IP = вердикт
- M4 DNS: нет утечки — запрос резолвится через туннель (nslookup без/с прямым сервером)
- M5 маршруты: ip rule/table 88 соответствуют режиму, после отключения — пусто
- M6 панель: информер, графики, R/S не «едут» (скриншоты)

## Особые случаи
- RU-выход (vologda) НЕ открывает гео-блокированные LLM (сам exit в RU) →
  для теста гео-разблокировки выбираем DE/NL/US сервер.
- Hysteria2-серверы: конфиг не генерируется (TODO) — проверка явной ошибки.
- Провайдерский DNS-отравленный ответ vs туннельный 1.1.1.1 — сравнить A-записи.
